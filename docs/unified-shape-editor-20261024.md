# Unified native dimensions and net weight editor

Domestic-only product General → 尺码与外形 · 每双净重 now edits the same specification records used by product parameter tables, comparison, numeric filters and the shape/weight panels. Separate `_pc_shape_dimensions` / `_pc_shape_sizes` controls and read paths were removed. Pre-deployment inspection found no nonempty legacy values locally or on the domestic server; old metadata is retained, not deleted. Model-level reference measurements are explicitly labeled and never silently inherited into a SKU.

Rows group variations by every non-color attribute, keeping size, cuff height and J02/J03 style separate. Same values across all group colors are prefilled; mixed or missing color values remain blank with a difference placeholder and expandable exact records. Explicit group confirmation applies changed fields to current group members, not future variations. Individual exceptions stay editable in 商品参数. Empty inputs preserve data; deliberate withdrawal remains in 商品参数. Existing measured leg heights take priority over catalog heights, which retain uncertain-endpoint labeling.

Input centimeters convert explicitly to dictionary millimeters; net pair weight stays grams. Staff choose current-change source and date; explanatory notes are optional. Manual entries require confirmation of dry relaxed measurement, heel/leg boundary to cuff (excluding heel curve), rear heel to toe tip and unpackaged pair weight; actual sample-pair count defaults visibly to one and is editable. Routine length/weight measurements have a narrowly scoped validation path (`manual_flat_v1`) without laboratory batch/termination requirements. Performance and other laboratory claims keep their original rules. Supplier input remains supplier-declared, with catalog height separate from confirmed leg height. Notes and source snapshots remain in private evidence; they are not laboratory results.

Native Update publishes only changed measurements through Repository::edit, with immutable prior revisions and atomic publication replacement. Multi-variation edits acquire all existing SKU locks in stable order and commit in one transaction. A product-bound nonce, edit/publish capabilities, signed scope/record fingerprint, complete-form check, strict numbers, explicit source, and under-lock stale-state recheck reject unsafe or partial edits. Validation failures retain entered form values for correction. There is no stock, price, native shipping weight or product-status mutation.

Public weight summaries group equal values within each size/cuff/style and only list colors when that same group has missing or differing values. Missing L data no longer adds unnecessary color lists to a fully covered M group. Net pair weight shows “约”; packaging-inclusive weights are excluded. Unknown catalog leg endpoints no longer get a calibrated vertical measurement arrow. Ordinary size diagrams read structured records and show their measurement basis; product-level fallback remains explicitly a model reference.

No sample measurement has been invented or changed by this release. Users enter their actual measurements after refreshing the product editor.
