## Detailed rulebook
**Filtering:** only published numeric claims; missing values never masquerade as a zero. Filter semantics explicitly displayed: e.g. 'cotton ≥ 75%' means a published cotton percentage. Results obey WooCommerce visibility/status. Paginate; allow sorting only against allowlisted fields.

**Comparison:** select min 2 max 4 IDs; products must be public WC catalog items. Reject/ignore unexpected IDs. Display product/variation-specific scope, test units and conditions. Missing vs not comparable are distinct states. Price from WC at request time; show price range if variable item has no chosen variant.

**Evidence:** a lab logo or accreditation label must not be fabricated. Report attachments should have explicit public/private visibility and sanitized names. External URLs should be allowlisted by scheme (HTTPS). Retracted claims must no longer appear as current.

**Publishing:** only authorized roles can change status. A new version can supersede old published evidence without erasing its audit record. Each publish action validates type/range/unit and required provenance.

**CSV:** define a template header plus import dry-run and per-row errors. CSV must not trigger published status without explicit authorization and validation. Formula injection prevention on export. Import could be deferred until after MVP core if timeline constrained.

**Customer policy links:** standard shop legal/returns/shipping pages are provided/configured by operator, not autogenerated as jurisdiction-specific legal advice.
